История версий до 1.0.0 — в репозитории
[CommCodeChecker](https://github.com/UncleKamineko/CommCodeChecker/blob/main/CHANGELOG.md)

## [1.0.0] — 2026-10-04

Первая версия на WPF. Правила обработки не менялись: на одних и тех же данных выходные
файлы совпадают с CommCodeChecker 0.9.0.

### Добавлено

- Интерфейс на WPF: четыре вкладки, окно справки, окно настроек программы.
- Распространение одним exe со встроенной средой .NET 8: на компьютере пользователя
  ничего устанавливать не нужно.
- Групповая проверка и проверка для ИМ выполняются в фоне: окно не «замирает»,
  во время анализа можно переключаться между вкладками.
- Кнопка «Прервать анализ» на вкладке «Групповая проверка»; незаконченная папка
  результатов удаляется.
- Индикатор прогресса: «бегущая» полоса во время чтения файла, затем 0–100 %.
- Подтверждение при закрытии программы во время обработки.
- Запрос о несохранённых настройках анализа при закрытии программы
  (раньше — только при переходе на другую вкладку).
- Блокировка сохранения настроек и смены файлов правил ИМ на время обработки.
- Цветовые схемы интерфейса: светлая, голубая, зелёная, бежевая, серая, лавандовая
  (окно «Настройки программы»).
- Сохранение размера и положения окна.
- Собственный заголовок окна; векторные значки кнопок «Справка» и «Настройки».
- Поддержка разного масштаба экрана на нескольких мониторах (Per-Monitor DPI).
- Вкладка «Один код»:
  - исходный код с выделенными изменёнными символами показывается под полем ввода;
  - изменённые пробелы отмечаются фоном;
  - при вставке из Excel отбрасывается перевод строки.
- Вкладка «Групповая проверка»:
  - при некорректной структуре файла указывается причина (например, файл открыт в Excel);
  - кнопка «Копировать сводку».
- Вкладка «Проверка для ИМ»: при переходе на вкладку сразу показывается папка
  последней групповой проверки.
- Самопроверка (Ctrl+Shift+T) — в отдельном окне с прокруткой и кнопкой «Копировать».
- Замечания при загрузке файлов конфигурации показываются после запуска программы.
- Справка: ссылки открываются одним щелчком, масштаб — Ctrl + колесо мыши.
- Автоматические тесты (xUnit) и сборка в GitHub Actions; публикация zip к релизу.

### Изменено

- Настройки разделены: `settings.json` — настройки анализа (формат CommCodeChecker),
  `ui-settings.json` — шрифты, цветовая схема и положение окна. Размеры шрифтов при
  первом запуске берутся из `settings.json` CommCodeChecker.
- Окно «Настройки программы» использует постоянные размеры шрифтов и не зависит
  от настроек шрифтов программы.
- Ширина кнопок выбора файлов конфигурации и файлов правил ИМ подстраивается под размер шрифта.
- Сводка групповой проверки выводится в две колонки, счётчики выровнены по правому краю.
- Логика обработки вынесена в отдельную библиотеку `CommCodeVerifier.Core`
  без зависимостей от интерфейса.
- Перезагрузка конфигурации подменяет её целиком: начатая обработка до конца работает
  с прежним набором файлов.
